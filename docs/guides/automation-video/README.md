# فیلمِ آموزشیِ کارتابل اتوماسیون

خروجی: `Client/wwwroot/media/automation-guide.mp4` (+ پوستر `automation-guide.jpg`)،
که دکمه‌ی «آموزش» در سربرگِ `/automation/tasks` پخشش می‌کند.

## ساختن دوباره

```bash
node docs/guides/automation-video/render.cjs                    # فیلمِ کامل (حدود ۳–۵ دقیقه)
node docs/guides/automation-video/render.cjs --shots 6.8,26.6   # فقط چند فریمِ PNG در .build/ برای بازبینی
```

نیازها: Playwright همان که `Tests/e2e` نصب کرده (`npm install` در آن پوشه)،
`ffmpeg` در PATH، و `python` با `numpy`.

پیش‌نمایشِ زنده: `guide.html` را از یک سرورِ ایستا روی ریشه‌ی مخزن باز کنید
(فونت و آیکون‌ها با مسیرِ نسبی از `Client/wwwroot` می‌آیند). `?t=26.6` یک فریمِ ثابت
نشان می‌دهد.

## چطور کار می‌کند

| فایل | نقش |
|---|---|
| `guide.html` | صحنه‌ها. `window.render(t)` همه‌چیز را برای ثانیه‌ی t می‌چیند — هیچ transition یا animationِ CSS نیست، پس هر فریم دقیق و تکرارپذیر است. `window.SFX` فهرستِ رویدادهای صداست. |
| `render.cjs` | با Playwright هر فریم (۳۰ در ثانیه، ۱۹۲۰×۱۰۸۰) را رسم و عکس می‌گیرد و JPEGها را مستقیم به ffmpeg می‌دهد. |
| `audio.py` | موسیقیِ پس‌زمینه و افکت‌ها (کلیک، تایپ، باز شدنِ پنجره، دینگ) را از روی `SFX` با numpy می‌سازد. |

برای تغییرِ یک صحنه: زمان‌بندی در `SCENES` (زیرنویس‌ها)، `PATH` (مسیرِ نشانگر و کلیک‌ها)،
`KEYS` (کلیدهای روی صفحه) و `CAM` (زوم) است؛ حالت‌های هر عنصر در `render` با
`seg(t, a, b)` از زمان به ۰..۱ تبدیل می‌شوند.

داده‌ها ساختگی‌اند — نام‌ها و شماره‌ها ربطی به مشتری‌ها ندارند.
